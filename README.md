# Buxmont Contractors — Website Mockup

A three-page homepage mockup for Buxmont Contractors, a Bucks/Montgomery County, PA
design-build residential contractor. Built from the brochure the client provided
(services, process, capabilities, and photos are sourced directly from it).

## Pages

- `index.html` — Home
- `services.html` — Services (full detail on all six offerings)
- `contact.html` — Contact / book an estimate

Each file is a single self-contained HTML page (fonts and images inlined as data
URIs), so any of them can be opened directly in a browser with no build step or
server required.

from the hosted preview links above.

## Design system

Roboto Slab (headlines) + IBM Plex Sans (body) + IBM Plex Mono (phone number
only), a restrained ink/paper/sand palette with a single brick-red accent, no
gradients or rounded cards, and real project photography extracted from the
client's brochure PDF.
